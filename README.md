# Bronze Standard — platform MVP

The brand, trust and editorial site for Bronze Standard LLC, built from **Variant A — Master Prompt v2.1**. It is not a booking engine, payment processor or age-assurance system, and it carries no explicit imagery.

**Status: preview for counsel review (Gate 6 open).** Until `SITE_PUBLIC=true`, every response is `noindex` and a preview banner shows.

---

## 1. Art direction

A private institution on bone paper. The page is a quiet field of `#F6F3EE` ruled by 8% ink hairlines. Type does the work: Fraunces at optical size for the headlines, set tight; Geist for reading; Geist Mono for anything counted. One bronze object stands in the hero, lit like a museum piece, and it is the only large use of bronze on the site. Motion is slow and expo-out, and it happens only where it carries meaning: lines rise into place, figures count once, the camera moves closer as you scroll. The 1998 Helmut Lang reference is about subtraction. Each section holds one idea, uses three type sizes at most, has one accent, and leaves a lot of space empty.

Tokens: [`styles/tokens.css`](styles/tokens.css), mapped into Tailwind v4 in [`app/globals.css`](app/globals.css) (the default palette is removed).

### Assumptions (one line each)

- **The roster is empty by default.** No talent exists yet, so six `[PLACEHOLDER]` profiles show only when `SHOW_PLACEHOLDERS=true`, and never on a Vercel production deploy.
- **Applications are visible but disabled until Gate 0 clears.** The `/apply` form renders so counsel can review the questions, and the handler refuses submissions.
- **Takedown is never gated.** It is a safety function.
- **The application steps share one page** (eligibility → questions → consent), so the form works without JavaScript.
- **The custom cursor is omitted.** Variant A marks it optional; leaving it out removes a focus-visibility risk.
- **The hero poster uses `<picture>`, not `next/image`.** It needs art-directed sources by breakpoint and colour scheme, which `next/image` cannot switch.
- **The 18+ notice makes every route dynamic.** The acknowledgment cookie is read on the server, which is required for the notice to work without JavaScript.

## 3. Motion justification

| Effect | What it serves | Reduced motion | Touch / mobile |
| --- | --- | --- | --- |
| Hero depth field (rotation, pointer parallax) | Hierarchy: establishes the single object and the site's register | No 3D; static poster | Not loaded below 768px |
| Scroll-time camera (8 → 4.5 units, +38°, pinned 200vh) | Hierarchy: hands the hero off to Section 02 | Not created | Not loaded |
| Text mask reveal (900ms, 80ms stagger) | Hierarchy: reading order of headlines | Text shown immediately | Same as desktop |
| Magnetic CTA (≤ 6px within 120px) + growing rule | Intent: confirms the primary action under the pointer | Off | Off |
| Tilt cards (≤ 6°, specular) | Intent: rewards attention on comparable items | Off | Off |
| Horizontal roster (pinned) + counter | State: position within the roster | Vertical grid | Vertical grid |
| Data count-up (once, 900ms) + underline | State: the figure has loaded and is final | Final value immediately | Same |
| Command palette fade (180ms backdrop, 420ms panel, CSS) | State: a layer opened | Instant | Same |
| Page curtain (420ms) | State: route changed | None (instant cut) | Same |
| Skeleton shimmer (1.6s) | State: loading | Static | Same |
| Scroll rail | State: progress through the page | Hidden | Hidden below 1024px |
| Header bar after 120px | State: scrolled | Instant | Same |

**What the failures mean**

- **Mobile initial JS ≤ 120 KB cannot be met with the mandated stack.** Next.js 16 plus React 19 alone download about 127 KB gzipped before any app code. Everything removable has been removed; the 23 KB above the floor is the site itself. Recommendation: amend the budget to ≤ 160 KB.
- **Mobile LCP 2.3–2.6 s against 2.0 s.** The LCP element is the 2 KB mobile poster. Under simulated slow 4G it waits behind the HTML, CSS and two preloaded fonts. Deferring the body font cut LCP but caused CLS 0.10, so I kept CLS at 0. Next lever: serve the poster inline in the HTML so it needs no request.
- **Desktop home TBT is a GPU-less artefact.** The test browser renders WebGL in software, so each frame is a long task. The new stop-the-scene fallback (below 20 fps for 2 s, return to the poster) cut it from about 12 s to 2.7 s here. Measure on real hardware before judging it.

**Changes made to meet the budgets (deviations from Variant A)**

| Specified | Shipped | Why |
| --- | --- | --- |
| Motion for layout and gesture | CSS transitions plus about 30 lines of pointer code | Motion cost 42 KB of initial JS for three small effects |
| drei `<Environment>` and `<AdaptiveDpr>` | three's RGBELoader + PMREM; own quality tiers | drei added 24 KB to the 3D chunk |
| RectAreaLight key | DirectionalLight key; the HDR carries the warm softbox | The rect-area lookup tables were about 100 KB of the 3D chunk |
| GSAP and Lenis on every page | Loaded only at ≥ 768px, no reduced motion, after first interaction or 1.2 s idle | 54 KB out of the initial load; phones never download them |
| Quality tier: one step | Two steps: below 50 fps drop effects and DPR; below 20 fps stop the scene | Protects weak hardware |
| `geist` package fonts | `next/font/google` Geist and Geist Mono | Allows the mono face to skip preloading |
| Brushed (anisotropic) metal | Plain physical metal | Anisotropy needs texture coordinates the geometry lacks; it rendered white |

### Storage

Records are AES-256-GCM files under `DATA_DIR`. Vercel's filesystem is not persistent, so before production either mount persistent storage or replace `FileStore` in `lib/store.ts` with a database adapter implementing `RecordStore` (Postgres or KV). This is part of Gate 4.

### Mail

`MAIL_TRANSPORT=console` prints magic links and custodian notices to the server log and is refused in production. Wire a transactional provider in `lib/mail.ts` before launch.

## Self-review

1. **Helmut Lang or fragrance ad?** Private-bank report. I removed the custom cursor, kept bronze to one object and hairlines, and let the figures be em dashes rather than dressing them up.
2. **Every animation earns its place?** Yes; see the motion table. Each one serves hierarchy, state or intent, and has a fallback.
3. **Keyboard-only?** Yes for the palette and the notice (automated). The keyboard walkthrough of /apply and /takedown is still to do by hand; both are native forms.
4. **JavaScript off?** Yes: every route renders, the notice acknowledges, and takedown submits and returns a case ID with JavaScript disabled.
5. **Unverifiable numbers?** None on screen. All Baseline values are null with n = 0. The only figures shown are contract terms and published fees.
6. **Is the 3D doing work CSS could not?** It does: real metal shading under a studio light, plus the scroll-time camera move. A CSS fallback exists, and it is what mobile and reduced-motion visitors get.
7. **Could anything identify or locate a talent who has not opted in?** No. Only the `public` tier is listed, `private` never renders, and legal names, locations and schedules are not in the data model.
8. **Verification?** All 15 automated checks pass. Three budgets fail: mobile initial JS (a framework floor), mobile LCP (2.3–2.6 s) and desktop TBT (measured without a GPU). Section 5 has the detail.
